# Bella Madalena, Casa dos Pães

Página de vendas da padaria: vitrine por categoria, sacola que monta o pedido e envia pelo WhatsApp, relógio das fornadas e encomendas.

Feita com Vite, React, Tailwind CSS e shadcn/ui.

## Rodar no computador

```bash
npm install
npm run dev
```

## Mudar dados da padaria

WhatsApp, endereço, Instagram, horários, fornadas e produtos ficam em `src/config.ts`.

## Publicação

Cada push na branch `main` publica o site no GitHub Pages pelo workflow `.github/workflows/deploy.yml`.
